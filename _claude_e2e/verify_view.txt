本章类型：INTRODUCE
本章要走的推演：把光当作一种电磁波 → 但单一波长无法解释一束白光过棱镜后展开成彩带 → 于是长出可见光谱与波长-颜色对应
本章目标：让学习者先从一束看似单纯的太阳光出发，发现它内部混着许多波长，并初步建立波长与颜色的对应，暂时不看天空。
应当想通的问题：为什么一束看起来是白的太阳光，能展开出好几种颜色？；彩虹一样的彩带里，颜色是按什么顺序排的、凭什么这样排？；既然红和蓝只是波长不同，那『颜色』到底是光的属性还是眼睛的属性？
开头处境：正午，林越把一束太阳光引到窗台那枚旧棱镜上，本以为会在白墙上看到一个更亮的光点，结果却是一道从红到紫的彩带。
本章因果契约：- 开头问题：一束看起来单纯无比的白光，凭什么经过一枚棱镜就展开成一整条彩带？
- 原有直觉/旧方法：光既然是已经讲清的一种电磁波，那单色光过棱镜至多整体偏折一下，白点该还是白点。
- 遇到的阻碍：墙上的不是偏移的白点，而是从红到紫连续排开的彩带；单一波长的图像解释不了『一种光里开出多种颜色』。
- 需要的新解释：必须弄清白光本身是不是『一种』光——它内部混着哪些波长，波长与看到的颜色又是什么对应关系。
- 新引入：可见光、电磁波谱、棱镜色散、波长与颜色的对应
- 应用：光的干涉与衍射
- 必须走到的拍子：用棱镜把太阳光投向白墙，观察到彩带 → 拿单波长假设试解释，只能得到偏折 → 引入『白光=连续混合』重读彩带 → 以彩虹为对照，沿带读出红到紫的波长顺序
- 可观察变化：白光不再是『一种』光，而是可见光谱的总和；颜色第一次有了可测量的物理坐标。
- 留给下一章的问题：这些波长穿过看似透明的整层大气时各自会遭遇什么？天空的颜色似乎就藏在那一步里。

## 输出

`issues` 数组，每项包含：`type`、`blockId`、`message`（具体指出问题在哪、为什么是问题）、`suggestedFix`。没有问题时 `issues` 为空数组。

`type` 只能用上面列出的那几个值，原样填写，不要自己改写或新造。

`blockId` 必须原样复制正文里那一段的 `[blockId: xxx]`。这个字段决定用户能不能**只重写出问题的那一段**：
- 填对了：用户可以只改这一段，整章其余部分一个字不动。
- 定位不到具体段落（例如「全章推演的节奏偏快」）就填 null。这很正常，如实填。
- **填一个不存在或者不相干的 blockId 是最坏的情况**：用户会打开一段没有问题的正文，看不出问题在哪。宁可填 null。

`unverifiedClaims` 数组，每项一句话，写清"哪个断言需要核对什么"。

## 契约检查（checks）

除 `issues` 外，还要输出 `checks` 数组：**对契约的 `appliedNodeTitles` 和 `introducedNodeTitles` 里的每个知识点，逐项给出正文证据判定**：

```json
{
  "nodeTitle": "被检查的知识点标题（必须与契约中的标题一致）",
  "claim": "APPLIED",
  "evidence": "PRESENT | PARTIAL | ABSENT | UNKNOWN",
  "evidenceBlockIds": ["定位到正文的 blockId，无证据就空数组"],
  "comment": "一句说明"
}
```

`evidence` 判定口径（**防误报，宁可 UNKNOWN 不要虚报 PRESENT**）：
- `PRESENT`：正文有明确的应用/引入证据，且你能定位到具体段落（填 `evidenceBlockIds`）；
- `PARTIAL`：正文提到了这个概念，但没有真正用起来（只提了名字、没走完判断/选择/行动）；
- `ABSENT`：正文根本没有对应内容；
- `UNKNOWN`：你无法判断（例如正文缺失、上下文不足）——**不要因为「没找到证据」就直接写 ABSENT**，区分「确实没有」和「无法判断」。

`claim`：`APPLIED`（契约要求应用）、`INTRODUCED`（契约要求首次引入）、`RESULT`（应用后是否有可观察结果）。
## 证据边界（硬约束，违反即判定错误）

**只能依据正文 blocks 判定 `evidence`。** 契约、路线、声明、检查目标或模型自身知识都不是正文证据。

- 正文未出现目标概念，且没有表达该概念所需的关键事实关系 → 必须判 `ABSENT` 或 `UNKNOWN`，**不得判 `PRESENT`**；
- 「契约/本章计划/推演骨架里提到这个概念」不等于「正文引入了这个概念」——声明不是证据；
- 只有当你能在正文里指出**具体段落**承载了该概念的引入/应用时，才能判 `PRESENT`（并填 `evidenceBlockIds`）；
- 拿不准时判 `UNKNOWN`，宁可 UNKNOWN 不要虚报 PRESENT。

主题：天空为什么是蓝色的
本章应当想通的问题：为什么一束看起来是白的太阳光，能展开出好几种颜色？；彩虹一样的彩带里，颜色是按什么顺序排的、凭什么这样排？；既然红和蓝只是波长不同，那『颜色』到底是光的属性还是眼睛的属性？
本章知识点：
- 可见光：为回答『我们眼睛到底接收光的哪一段』而存在：人眼能响应、并由此产生颜色感觉的那部分电磁辐射，约380到750纳米。
    来处：要解释颜色，先得划出『能被看见』的光的范围
    去处：这段可见的光本质上是什么？要请出电磁波谱
    易混：易与『光』整体混：可见光只是电磁波里极窄的一段，红外紫外都看不见
- 电磁波谱：为回答『可见光在物理上属于什么』：按波长排列的电磁辐射全家，无线电到伽马射线连续分布，可见光只是其中一小段。
    来处：可见光被划出来后，自然要问它在全谱里坐哪把交椅
    去处：光既然是波，凭什么能被拆开——引出干涉衍射与波长本质
    前置：可见光
    易混：易把『颜色』等同于『单一波长』：颜色是感知，波长是物理量，并非一一对应
- 棱镜色散：为回答『白光里是不是混着多种成分』：玻璃对不同波长折射率不同，白光过棱镜被按波长拉开成连续色带。
    来处：知道光是波还不够，需要一个把混合光分开的操作
    去处：色散说『白光=多色混合』，但凭什么波长与颜色能对齐——要用干涉精确测波长
    前置：电磁波谱
    易混：易与彩虹成因混：棱镜靠折射色散，彩虹靠水滴内折射+反射+再折射；易以为『色散创造了颜色』：颜色本就在白光里，棱镜只是摊开它
- 光的干涉与衍射：为回答『波长能不能被精确测量』：光遇缝或遇双路叠加产生明暗条纹，条纹间距直接给出波长数值，把颜色钉在确定的纳米上。
    来处：色散只给了『红长紫短』的定性顺序，要定量就必须测出每个颜色的波长
    去处：有了精确波长刻度，波长与颜色的对应关系才立得住
    前置：电磁波谱；棱镜色散
    易混：易与色散混：干涉/衍射是波叠加，色散是折射率随波长变，两者机制不同；衍射条纹与干涉条纹易混：前者来自单缝/光栅，后者来自双路相位差
- 波长与颜色的对应：为回答『物理量波长如何映射到主观颜色』：在可见光范围内，长波偏红、短波偏紫，建立从纳米数到颜色名的对应表。
    来处：干涉衍射给了精确波长，需要一把把波长翻译成颜色的尺
    去处：对应表只解释了『物体是什么颜色』，还没解释『天空为什么是蓝的』——那是散射的活
    前置：光的干涉与衍射；棱镜色散
    易混：易把『对应』当『一一对应』：同一种颜色可由不同波长混合产生，紫红甚至不在单色光谱上
