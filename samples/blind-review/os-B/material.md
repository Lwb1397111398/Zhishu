# 盲评材料：主题 os 方案 B

## 路线（演进主线）
1. 单道顺序执行 → 解决了“让程序先能跑起来”的问题
2. 多道程序与进程抽象 → 解决了“CPU和设备别闲着、多个程序能交替跑”的问题
3. 调度、生命周期与上下文切换 → 解决了“多个就绪程序该谁上、如何安全切来切去”的问题
4. 同步、通信与死锁处理 → 解决了“多个进程一起工作时不抢乱、不卡死”的问题
5. 内存抽象与地址映射 → 解决了“多个程序如何共存内存且互不踩脚”的问题
6. 虚拟内存与分页机制 → 解决了“程序比内存大、内存利用率低、地址隔离不彻底”的问题
7. 文件抽象与目录权限 → 解决了“数据如何持久命名、共享、保护并按路径找到”的问题
8. 文件系统实现与统一抽象 → 解决了“文件如何落到磁盘、多设备如何统一访问并与内存协同”的问题
