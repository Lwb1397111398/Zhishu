# 知述（Zhishu）

把结构化知识转化为连续故事的 Android 学习工具。

## 产品定位

不是“小说生成器”，而是“故事化学习系统”。故事是主要入口，知识地图是导航，搜索是定位工具：

主题 → 知识主干 → 讲述路线 → 分章生成 → 事实核验 → **连续阅读**（知识点 ⇄ 知识地图 ⇄ 正文定位）

测验与间隔复习是可选辅助，默认不进主线（数据与页面全部保留，可在「我的」页开启）。

## 已实现功能（MVP）

- **学习工作台**：项目列表、继续阅读（按块恢复位置）、一键载入示例项目（民法继承案）
- **创建项目向导**：主题、基础水平、学习深度、故事类型、每日时长、目标天数，以及资料添加（粘贴文本 / 网页地址 / 文件选择）。全部资料解析成功后才在单个事务里落库，中途失败不留半成品项目
- **资料中心**：TXT / Markdown / PDF / URL 解析（解析与抓取都在 IO 线程），内容去重，资料删除
- **知识地图**：树形展示、展开/折叠、节点详情（来处/去处、定义、前置、易混淆、案例、来源），**「在故事里读它」可直接跳到对应章节的具体正文块**，确认标记、掌握度，并展示模型报告的资料缺口与资料冲突
- **故事大纲**：章节列表、状态流转、章节标题/剧情目标/知识点编辑、后台生成（WorkManager，按显式阶段执行、断网重试）、核验说明与失败重试入口
- **阅读器**：`LazyColumn` 按块渲染（稳定 `key`，长章节不再一次性组合全文）、安静/密集模式、知识块高亮、**本章导览**（本章解决什么、学习目标、涉及知识点、关键结论可跳转）、知识点卡片可回跳知识地图、上下章导航、**阅读进度按「章节 + 正文块 + 块内偏移」保存**
- **知识搜索**：跨知识点、章节正文、资料原文搜索，走 FTS 倒排索引，**命中后定位到具体正文块并短暂高亮**
- **章节自测**：回忆题（自评）/ 判断题 / 案例题，放在章末「自测」按钮里由用户主动开启，不自动弹出、不阻塞下一章；答题记录持久化、掌握度一题只计一次
- **复习中心（可选）**：间隔复习（1/3/7/14/30 天）。默认关闭——关闭时不自动创建复习计划、首页不显示「今日复习」；在「我的 → 学习方式」开启后恢复完整节奏，已有数据不受影响
- **模型配置**：FAST / STORY / VERIFY 三种角色可分别配置兼容 OpenAI 接口的服务商（仅 https）；API Key 使用 Android Keystore 加密存储、密码方式输入，支持连通性测试
- **备份导入导出**：ZIP 格式，包含项目/资料/知识/章节/测验/进度，**绝不包含 API Key**；导入先整包校验再单事务写入，并有条目数/解压大小上限

## AI 生成流程

1. 创建项目（无资料模式只填主题即可）
2. 「知识主干」→ 梳理这门学科的演进主干（一个概念从哪来、又引出什么）
3. 确认知识点后「讲述路线」→ 规划世界观、人物、章节推演链与知识点分配
4. 逐章生成 → 分章正文 + 事实核验 + 自测题
5. 阅读（安静/密集）→ 知识点跳知识地图 → 搜索定位回正文 → 继续下一章

## 构建与运行

环境要求：

- Android Studio（自带 JDK 21）
- Android SDK（本项目使用 `E:\engine\androidstudioSDK`，见 `local.properties`）

```powershell
# 编译 Debug APK
.\gradlew.bat :app:assembleDebug

# 单元测试（131 个，含 Robolectric、Room 迁移与 Compose UI 测试）
.\gradlew.bat :app:testDebugUnitTest

# Lint 检查
.\gradlew.bat :app:lintDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`

## 数据库

- 当前版本：4。Room schema 导出到 `app/schemas/`，v1→v2、v2→v3、v3→v4 都提供了非破坏性 `Migration`（不使用 `fallbackToDestructiveMigration`）。
  - v3→v4：`reading_progress` 增加 `blockOffset`。阅读进度改为「章节 + 正文块 + 块内偏移」；旧的 `charOffset`（整章滚动像素）保留但不再写入——它换机型或字号就失效，也和搜索用的字符位置不是同一坐标系。
- 正文与资料片段各有一张 FTS4 索引表。中文子串检索靠**字符二元组**分词实现（FTS 默认分词器会把连续中文当成一个 token，FTS5 的 trigram 分词器要求 SQLite 3.34+，在 minSdk 26 上不可用）。

## 首次使用建议

1. 安装后进入「学习」页，点击「载入示例项目」，可直接体验知识地图、阅读器、测验与复习全流程
2. 体验完成后在「我的」页配置模型（三个角色分别填接口地址、模型名、API Key）
3. 创建自己的学习项目，粘贴教材/法条/讲义内容，开始生成专属故事

## 已知限制

- PDF 仅支持可复制文字的版本，扫描版 PDF 需要 OCR（标记为“扫描版”）
- 生成依赖网络与已配置的模型；核验环节会提示差异，需人工确认
- 模型接口与网页抓取只允许 https；应用已关闭系统备份（`allowBackup=false`），因为 API Key 绑定本机 Keystore，跨设备恢复无法解密
- 中文全文检索基于二元组，单字查询走前缀匹配，可能带回较多结果
